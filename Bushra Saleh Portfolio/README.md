# Bushra Saleh — Portfolio

Personal portfolio site for Bushra Saleh, Web Developer & UI / UX Designer.

## Tech stack

- Vite
- TypeScript
- React
- shadcn/ui
- Tailwind CSS

## Getting started

Requires Node.js & npm.

```sh
# Install dependencies
npm install

# Start the dev server (http://localhost:8080)
npm run dev
```

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the dev server with hot reloading |
| `npm run build` | Build for production into `dist/` |
| `npm run build:dev` | Build using development mode settings |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |

## Deployment

The build output in `dist/` is a static site and can be hosted on any static host
(Netlify, Vercel, GitHub Pages, Cloudflare Pages, etc.).
